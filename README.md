# 欽定儀象考成

清乾隆間敕撰，共三十卷。四庫全書子部天文演算法類推步之屬，文淵閣本冊 793。

本目錄是這部書的**版式復刻源文件** —— 用 LuaTeX 重排，而非重新錄入，也非 OCR。
行的起始格、每行字數、雙行小注的左右列、圖在葉上的位置，都是自文淵閣四庫全書
電子版的版式記錄直接讀出的，不靠文意推斷。共 875 葉。

## 排版

需要 LuaTeX 與 [luatex-cn](https://github.com/open-guji/luatex-cn) 的 `ltc-guji`
文檔類（正文字體 TW-Kai 隨其安裝）：

```bash
lualatex 欽定儀象考成.tex
```

排出 875 葉，版心居中，一葉十六行。正文用字全在 TW-Kai 之內，無缺字。

`.github/workflows/build.yml` 在 `texlive/texlive:latest`（每日自上游重建）裡
以當天的 LuaTeX 排一遍，PDF 與日誌放進 artifacts，保留 30 天。它同時把兩件
靜默失敗變成硬錯誤：日誌出現 `Missing character`，或葉數不是 875。

luatex-cn 須取 `main`（最新 release v0.4.1 尚無本書所需的修正），且要裝進
`TEXMFHOME/tex/lualatex/`：放進 `tex/latex/` 時 `.lua` 找不著，版式引擎會
靜默退化，正文塊一結束就報 `\prevdepth` 錯。

## 私用區字形的處理

原始資料把 15 個常用字的寫本字形另置於私用區，共 208 處。這些**並非
Unicode 無法表示的生僻字**，只是同一個字的另一款手寫寫法。早先的版本
保留私用區碼位、外掛 `Sk4PUA.ttf` 存其形；但缺字型時 LuaTeX 照樣編譯
成功，這 208 個字會靜默消失，且文字不可檢索。

## 來源與權利

底本為文淵閣四庫全書（清乾隆間寫本），已屬公有領域。版式與文字取自其電子版
的版式記錄。

本目錄的內容 —— `欽定儀象考成.tex` 與 `img/` 下的圖版 —— 是**原始文獻及其
圖片的衍生作品**：文字與版式記錄的是原書葉面，圖版是原書圖繪的忠實再現。
衍生自公有領域素材的成果，不因經過一道處理而重獲保護。

**據美國著作權法及相關判例，本目錄的內容屬於公有領域。** 理由如次：

1. **底本早已過保護期。** 《欽定儀象考成》成書於清乾隆十年至十九年間
   （1745–1754），撰者卒歿逾兩百年，任何法域的著作權保護期皆已屆滿。

2. **忠實複製不生新著作權。** 對平面公有領域作品的忠實影印、掃描或翻拍，
   因欠缺原創性，不產生新的著作權 ——
   *Bridgeman Art Library v. Corel Corp.*, 36 F. Supp. 2d 191 (S.D.N.Y. 1999)。
   `img/` 下的圖版即屬此類：它們是原書葉面的忠實複製，不含任何新增的
   創作性表達。

3. **「辛勤汗水」不構成著作權。** 投入的勞力、時間與經費本身不是受保護的
   標的；缺乏最低限度原創性的事實彙編不受保護 ——
   *Feist Publications, Inc. v. Rural Telephone Service Co.*, 499 U.S. 340 (1991)。
   還原版式所費的工夫，不能使公有領域的內容重獲保護。

4. **版式資料是事實而非表達。** 「某行自第幾格起、共幾字、是正文抑或雙行
   小注」記錄的是原書葉面的客觀狀態，屬事實而非創作選擇，本身不可著作權化。

同一方向的規則亦見於歐盟《數位單一市場著作權指令》(EU) 2019/790 第 14 條：
視覺藝術作品保護期屆滿後，其複製件除非本身具原創性，否則不受著作權或
鄰接權保護。

以上為本目錄維護者的立場說明，非法律意見。各法域規則不盡相同，
如有疑義請自行查證。
