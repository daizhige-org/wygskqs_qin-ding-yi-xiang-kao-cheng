# 欽定儀象考成

清乾隆間敕撰，共三十卷。四庫全書子部天文演算法類推步之屬，文淵閣本冊 793。

本目錄是這部書的**版式復刻源文件** —— 用 LuaTeX 重排，而非重新錄入，也非 OCR。
行的起始格、每行字數、雙行小注的左右列、圖在葉上的位置，都是自文淵閣四庫全書
電子版的版式記錄直接讀出的，不靠文意推斷。共 875 葉。

排出來是**朱欄墨書**，即原書的樣子：版框與欄線朱色，文字墨色，紙作米黃。

## 內容

```
欽定儀象考成.tex   由解碼工具自版式記錄生成，勿手改
tools/             colorize_plates.py 圖版分色，pdf_bookmarks.py 加書籤
img/               710 個 PNG，原書的圖版與插圖，已分為朱欄與墨字（見下）
                   0281.png 為葉 281 的圖；0281_1.png 為同葉的第二塊圖
README.md          用法、校驗結果、私用區碼位一覽、來源與權利
LICENSE            AGPL-3.0 全文
```

成品 PDF 不入庫（44 MB），按下面的步驟自行排出。

## 排版

需要 LuaTeX 與 [luatex-cn](https://github.com/open-guji/luatex-cn) 的 `ltc-guji`
文檔類，以及三支互補的字體（缺一即缺字，見下節）：

| 字體 | 覆蓋 | 用途 |
|---|---|---|
| TW-Kai | URO 99.7%、Ext-A 100% | 正文絕大多數字 |
| TW-Kai-Ext-B | Ext-B 100%、Ext-C 98.6% | 10 個考訂本字，共 50 處 |
| AR PL UKai TW | GB+Big5 楷體 | 只為「龯」U+9FAF 一處 |

前兩支見 luatex-cn 的 `scripts/download_fonts.py`，第三支是 Debian 的
`fonts-arphic-ukai`。裝好後：

```bash
lualatex 欽定儀象考成.tex
```

排出 875 葉，版心居中，一葉十六行，朱欄墨書。再加書籤（需
`pip install pikepdf`）：

```bash
python3 tools/pdf_bookmarks.py 欽定儀象考成.pdf 欽定儀象考成-bookmarks.txt
```

`-bookmarks.txt` 是排版時順帶寫出的，每葉一行「絕對頁碼 | 卷名」——
`.tex` 導言區掛了個 `shipout/before` 鉤子逐葉記下。共 37 條書籤：序、奏議、
職名、目録、提要、卷首上下、卷一至卷三十。

**書籤是後處理加的，不是 hyperref。** `\pdfbookmark` 的錨點會被 luatex-cn 的
網格引擎當成內容 —— 實測整本從 875 葉變 876 葉。版式復刻不能為了書籤改版面，
所以改成先排版、再往 catalog 裡寫 `/Outlines`，頁面內容一個位元組都不動。

`.github/workflows/build.yml` 在 `texlive/texlive:latest`（每日自上游重建）裡
以當天的 LuaTeX 排一遍，PDF 與日誌放進 artifacts，保留 30 天。它同時把兩件
靜默失敗變成硬錯誤：日誌出現 `Missing character`，或葉數不是 875；加完書籤後
再驗一次「37 條書籤 / 875 葉」。

## 圖版的朱墨分色

原書是朱欄墨書，但電子版的掃描件把欄線和字都印成了黑的。若原樣使用，彩色
模板只管得到引擎畫的最外圈版框 —— 純排版葉是滿版朱欄，圖版葉只有外緣一圈
紅邊，兩者對不上（本書 **701 / 875 葉帶掃描圖版**，只有 174 葉是純排版）。

`img/` 下的圖版因此已用 `tools/colorize_plates.py` 分過色：

```bash
python3 tools/colorize_plates.py colorize img   # 已跑過，結果入庫
python3 tools/colorize_plates.py restore  img   # 還原成原本的黑白
```

原掃描件是純 1-bit（只有 0 和 255，無反鋸齒），所以形態學處理乾淨：以長條
結構元素對墨跡做開運算取出欄線，再沿各自方向閉運算把被字壓斷的線接回來，
並與原墨跡取交集，保證不憑空生出墨。品質自檢：對「判為文字」那層再跑一次
分離，殘留長直線為 0 px。

**門檻取邊長的 1/8（約 160px）**，是被卷首標題頁逼出來的：那幾個大字
「庫」「全」「書」的中央豎筆有 100px 以上，早先取 1/25（約 51px）時被誤判
成欄線，字的筆畫跟著變朱。取 1/8 則大字筆畫全部保住，而星表的細分隔線仍在
——欄線橫貫整幅，比任何筆畫都長得多，兩者相隔很開。

插圖類圖版（儀器圖、渾象圖等 19 張）判出的欄線近乎為零，這是對的：它們本
就沒有表格線，通幅屬墨繪。

**分色可逆，不損失資訊。** 輸出是 3 色調色盤 PNG，`restore` 把朱與墨映回黑、
紙映回白，即得與原掃描件逐像素相同的 1-bit 圖 —— 分類只是把資訊分了層。

代價是圖從 1-bit 灰階變成 2-bit 調色盤，LuaTeX 不能再直接透傳、得展開重編：
編譯 23 秒變 151 秒，PDF 38 MB 變 44 MB，`img/` 37.2 MB 變 40.1 MB。

（另一條路是把白色轉成透明，讓紙色透上來。實測不可取：PDF 沒有調色盤透明，
LuaTeX 得為每張圖生成 SMask 軟遮罩，編譯 11 分鐘、PDF 漲到 110 MB，而且
只解決底色、解決不了欄線。）

**已知瑕疵**：版心的魚尾是實心塊不是線，開運算取不到，仍是墨色。

## 私用區字形的處理

原始資料把 15 個字的寫本字形另置於私用區，共 208 處 —— 這些**並非 Unicode
無法表示的生僻字**，而是常用字的另一款手寫寫法。早先的版本保留私用區碼位、
外掛 `Sk4PUA.ttf` 存其形；但缺字型時 LuaTeX 照樣編譯成功，這 208 個字會靜默
消失，且文字不可檢索。

現已全部換成標準碼位。對應字主要取自
[wyg-sikuquanshu-decoder](https://github.com/daizhige-org/wyg-sikuquanshu-decoder)
的 `data/font/skchar_pua.json` —— 即維基文庫 `Module:SKchar` 的考訂本字，
15 個碼位它給出 12 個；`U+EEEE` 該檔留空，本專案另行考訂為 `𩆝` U+2919D，
已回填至該倉庫的 `data/font/extra/欽定儀象考成.json`。

於是 **13 個有專屬碼位，存形與可檢索兼得**；餘 2 個 Unicode 未收，退取常用字。

### Unicode 未收者（2 個，共 154 處）

| 私用區碼位 | 次數 | 退取 | 標準碼位 | 前後文 |
|---|---:|:---:|---|---|
| U+EB8E | 125 | 弦 | U+5F26 | 度之通**弦**等又取內界圓 |

`skchar_pua.json` 對這兩個碼位的 `uni` 欄留空。把原書字形自 `Sk4_PUA.json`
的輪廓畫出來，與候選異體字（`絃/琁`、`点/㸃`）逐一比對，確認只是寫本筆勢
差異，Unicode 沒給獨立碼位。這 154 處（**佔全部 208 處的 74%**）只能取常用
字，失去原書的那一款字形。

（另有一說：這兩個字形見於 WFG Full Sung 的私用區 `U+F0F5E`、`U+10283D`
—— 但那仍是私用區碼位，換過去等於把字型依賴從一支換成另一支，故不取。）

## 來源與權利

底本為文淵閣四庫全書（清乾隆間寫本），已屬公有領域。版式與文字取自其電子版
的版式記錄。

本目錄的內容 —— `欽定儀象考成.tex` 與 `img/` 下的圖版 —— 是**原始文獻及其
圖片的衍生作品**：文字與版式記錄的是原書葉面，圖版是原書圖繪的忠實再現，
另經一道機械分色（見〈圖版的朱墨分色〉）。衍生自公有領域素材的成果，不因
經過一道處理而重獲保護。

**據美國著作權法及相關判例，本目錄的內容屬於公有領域。** 理由如次：

1. **底本早已過保護期。** 《欽定儀象考成》成書於清乾隆十年至十九年間
   （1745–1754），撰者卒歿逾兩百年，任何法域的著作權保護期皆已屆滿。

2. **忠實複製不生新著作權。** 對平面公有領域作品的忠實影印、掃描或翻拍，
   因欠缺原創性，不產生新的著作權 ——
   *Bridgeman Art Library v. Corel Corp.*, 36 F. Supp. 2d 191 (S.D.N.Y. 1999)。
   `img/` 下的圖版即屬此類：它們是原書葉面的忠實複製，不含任何新增的
   創作性表達。分色一步同樣不生新著作權 —— 它以固定的形態學規則判定哪些
   墨跡是欄線、哪些是筆畫，逐像素可逆（`restore` 即還原為原掃描件），
   全程無取捨、無創作選擇；且它還原的正是原書本有的朱墨之分，並非新增。

3. **「辛勤汗水」不構成著作權。** 投入的勞力、時間與經費本身不是受保護的
   標的；缺乏最低限度原創性的事實彙編不受保護 ——
   *Feist Publications, Inc. v. Rural Telephone Service Co.*, 499 U.S. 340 (1991)。
   還原版式所費的工夫，不能使公有領域的內容重獲保護。

4. **版式資料是事實而非表達。** 「某行自第幾格起、共幾字、是正文抑或雙行
   小注」記錄的是原書葉面的客觀狀態，屬事實而非創作選擇，本身不可著作權化。

同一方向的規則亦見於歐盟《數位單一市場著作權指令》(EU) 2019/790 第 14 條：
視覺藝術作品保護期屆滿後，其複製件除非本身具原創性，否則不受著作權或
鄰接權保護。

以上為本目錄維護者的立場說明，非法律意見。各法域規則不盡相同，
如有疑義請自行查證。
